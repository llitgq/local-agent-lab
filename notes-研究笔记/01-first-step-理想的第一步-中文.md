# 📝 01 · 理想的第一步：先用免费的试水，再谈设备

[English](01-first-step-理想的第一步.md)

> 如果你今天想入局本地智能体，我心里理想的第一步是这样的——它跟我实际走过的路，正好相反。
>
> 2026-10-30

## 🖥️ 设备：从你的老电脑开始

想入门本地 Agent，**优先用自己手上的老电脑**。动手前先把里面的内容、个人详细信息都拷贝出来——挪到一块硬盘或上传网盘——然后装一个**干净的 系统**再开跑。

原因很简单：本地智能体会拿到你机器的深度权限，**隐私是本地 Agent 的一等公民**。一台干净的老机器，既能试错，又不怕它把你重要的东西搞乱。

## ⏳ 什么时候才值得买新设备

我的建议：**等你跑通了几个工作流、它真正能不间断地替你干活之后，再去买专门的主机。**

说个反面教材——我自己。我当时已经有一台 NAS，然后冲动之下又买了一台 Mac mini。结果它闲置了很长一段时间：最开始根本跑不明白，每天的时间全浪费在试错、试错、再试错上，中间放弃过很多次，总觉得"这东西我怎么搞不明白"。但内心又是不服的：**为什么别人都能用得好，我就不行？** 就是靠这口气撑下来的。

回头看，那台 Mac mini 买早了。先跑通，再买设备，钱和信心都省。

## 🎁 现在是个难得的好行情

这个时代对新手是真的友好：市面上一批**免费的本地 AI 工具**——WorkBuddy、MiniMax Code、智谱、Qwen Code 等等——下载注册就送积分，给它权限，它就能**替你操作电脑**。

对比一下：你去问豆包、DeepSeek 一个问题，它们只能"回答你"，帮不了你动手。而这些免费工具是你跟它说一句话，它就直接上手干活。

更妙的一个玩法：**让这些工具替你安装 OpenClaw、Hermes 或者 Claude Code**——装环境这种劝退新手的活，一句话就外包出去了。

## 🔌 免费算力：白嫖即学习

免费模型和免费算力的网站现在很多——英伟达、OpenRouter、科大讯飞这些都有白嫖额度。**折腾这些免费算力的过程，本身就是最好的学习**：什么是 API、什么是请求地址、怎么把 API 接进本地的 Agent 程序——这些概念全在这一路顺手搞明白了。

免费额度里好用的模型不少：GLM、Flash 这些都拿得出来。我自己用 GLM 比较多。

顺带一个血的教训：我最早用 MiniMax，第一感觉是"这模型怎么这么傻"。后来才发现——**不是模型傻，是我配置写得不对**。所以模型表现拉胯的时候，先怀疑自己的配置。

## 🧰 偷懒也是生产力

我懒得研究 OpenClaw 和 Hermes 的配置文件格式，干脆给自己写了几个专门编辑这些配置文件的小工具。**懒不是问题，懒出工具来就是收获。**

## 🎯 一句话总结

**优先用免费的资源试水。**

- 对自己要求高 → 跑出一整套自己的流程之后，再去付费买更好的，这是最好的节奏
- 执行力一般 → 跑个七七八八，起码搞明白怎么接 API、怎么创建新的智能体，就可以上付费模型了
- 买之前多看看评测
- 千万别学我：当年像发现新大陆一样，把能买的模型全买了一遍。平心而论，Claude 确实好很多——但到了今天，**模型和模型之间的差距已经在逐渐缩小**，起步阶段真没必要烧钱

## 📌 名单就不列了

免费本地工具和免费 API 的具体站点，网上教程和视频一搜一大把，看一下基本就差不多了。学会自己找，也算第一步的一部分。

## ✅ 落地清单

- [ ] 找出那台旧电脑，资料和个人信息拷到硬盘/网盘
- [ ] 装一个干净的系统
- [ ] 下载 1–2 个免费本地智能体（注册送积分那种）
- [ ] 让它替你安装 OpenClaw / Hermes / Claude Code
- [ ] 注册 1–2 个免费算力站（NVIDIA / OpenRouter / 科大讯飞…）
- [ ] 把免费 API 接进智能体，跑通第一句对话
- [ ] 遇到"模型很傻"→ 先检查配置，再考虑换模型

# 📝 01 · The Ideal First Step: Free Resources First, Hardware Later

[中文版](01-first-step-理想的第一步-中文.md)

> If you want to get into local agents today, here is my ideal first step — which happens to be the exact opposite of the road I actually took.
>
> 2026-10-30

## 🖥️ Hardware: start with your old computer

To get into local agents, **use the old computer you already own**. Before anything else, copy its contents and personal data out — to a hard drive or cloud storage — then install a **clean system** and start from there.

The reason is simple: a local agent gets deep permissions on your machine, and **privacy is a first-class citizen for local agents**. A clean old machine lets you experiment freely without risking anything that matters.

## ⏳ When is it actually worth buying hardware

My advice: **wait until you've run a few workflows end-to-end and the agent genuinely works for you non-stop — then buy the dedicated box.**

Confession time — I did the opposite. I already had a NAS, then impulsively bought a Mac mini. It sat idle for a long stretch: at first I simply couldn't get things running. Every day burned away on trial and error, over and over. I quit more than once, thinking "I just can't figure this thing out." But I couldn't accept it: **if everyone else can use this well, why can't I?** That stubbornness is what carried me through.

Looking back, I bought that Mac mini too early. Run it through first, buy hardware second — you'll save both money and confidence.

## 🎁 A rare window of freebies

This era is genuinely friendly to beginners: there's a whole wave of **free local AI tools** — WorkBuddy, MiniMax Code, Zhipu (GLM), Qwen Code, and more — free to download, credits on signup, and once you grant permission, they **operate your computer for you**.

Compare: ask Doubao or DeepSeek a question, and they can only *answer* you — they can't act. With these tools, you say one sentence and they get to work.

The neatest trick: **have these tools install OpenClaw, Hermes, or Claude Code for you** — the exact chore that scares newcomers away, outsourced with a single sentence.

## 🔌 Free compute: freeloading as a learning path

There are plenty of free-model and free-compute sites now — NVIDIA, OpenRouter, iFlytek and others all hand out free quota. **The process of chasing these free credits is itself the best education**: what an API is, what an endpoint is, how to plug an API into a local agent program — you'll figure all of it out along the way.

There are solid models inside the free tier too: GLM, Flash, and friends. I personally use GLM the most.

One painful lesson: I first tried MiniMax and thought "this model is dumb as a rock." Turned out — **the model wasn't dumb, my configuration was wrong**. When a model underperforms, suspect your own config first.

## 🧰 Laziness is productivity

I couldn't be bothered to learn the config file formats of OpenClaw and Hermes, so I wrote myself a few small tools just for editing those configs. **Being lazy isn't the problem — turning laziness into tools is a win.**

## 🎯 The one-line summary

**Use free resources to test the waters first.**

- High standards for yourself → run a complete workflow of your own, then pay for better models. Best possible rhythm.
- Average follow-through → get 70–80% there, at least understand how to connect an API and how to create a new agent — that's the moment paid models become worth it.
- Read reviews before buying anything.
- Just don't copy me: back then I acted like I'd discovered a new continent and bought every model I could. To be fair, Claude really is much better — but today, **the gap between models keeps shrinking**, and there's no reason to burn money at the starting line.

## 📌 No lists here

As for the specific free tools and API sites — tutorials and videos are all over the internet, one search covers it. Learning to find them yourself is part of step one.

## ✅ Checklist

- [ ] Dig out that old computer; copy personal data to a drive or cloud
- [ ] Install a clean system
- [ ] Download 1–2 free local agents (the signup-credit kind)
- [ ] Have them install OpenClaw / Hermes / Claude Code for you
- [ ] Register on 1–2 free compute sites (NVIDIA / OpenRouter / iFlytek…)
- [ ] Wire a free API into your agent and get the first reply through
- [ ] "This model is dumb" → check your config before blaming the model

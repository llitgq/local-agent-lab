# 🧪 Local Agent Lab · 本地智能体实验室

[🇬🇧 English](README.md)

> 一个从业者泡在智能体里两年的田野笔记——我趟过的路、写完又被我迭代掉的工具、以及一路上踩过的每一个坑。

## 👋 我是谁

我是一个这两年一直痴迷探索 AI **智能体（Agent）** 的从业者。路线大致是 **OpenClaw → Hermes → Claude Code**，中间还穿插了各种各样的智能体。很长时间里，我从来没想过要分享什么——就是不停地搭、拆、再搭。

## 🎯 为什么建这个仓库

先坦白：这两年我烧掉了**海量的 Token**，但很长一段时间里，几乎什么都没留下来。没有笔记，没有总结，只有一种“跑得挺快”的感觉。

我是个工具痴。每次有新组件、新框架出现，我都忍不住上手——所以迭代速度很快。副作用就是：很多我写完的工具，已经被我自己迭代掉了、彻底不用了。**但它们是能跑的、写完了的，也确实可能帮到别人。**

一路走来——尤其是 OpenClaw 和 Hermes 阶段——我还做过不少真实的工作流和集成（飞书是重头），积累了一些不想让它蒸发的经验。

所以这个仓库与其说是“分享”，不如说是我想**用输出倒逼自己总结过往**。顺带如果能帮到你，那就更好了。🙌

## 🧭 写给新手

如果你是新手小白，或者正打算开始探索这些东西——这个仓库可以当作**一条已经被人趟过的路径**来看。你会看到哪些工具来了又走、哪些想法活了下来、坑都在哪。

现在流传一句话：**“只要你学得慢，其实就可以不用学了”**（反正 AI 越来越强，等着就行）。这话对，也不对。对，是因为工具确实会越来越好；不对，是因为如果你只是等，**其中的原理、探索的过程、还有搞明白一件事时的那种兴奋感，全都遗失了**。这部分是任何工具都给不了你的。

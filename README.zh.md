# Local Agent Lab

[English](README.md)

关于本地智能体的实战田野笔记——研究想法、可移植的 Skill，以及一份诚实的踩坑记录。一个坑一个文件，发现了就立刻记进来。

## 里面有什么

| 路径 | 装什么 |
|---|---|
| [`notes/`](notes/) | 本地智能体的研究与想法——一题一号 |
| [`skills/`](skills/) | 通过便携三关的自写 Skill |
| [`pitfalls/`](pitfalls/) | 踩坑录——一坑一文件，编号递增，再小也记 |

## 便携三关

Skill 想进 `skills/` 必须过三关：

1. **零硬编码路径**——一律走 `$HOME` 或参数
2. **环境契约**——README 写清依赖什么、在哪台机器测过
3. **一键自检**——附带验证环境的脚本

过不了三关的经验不会被丢掉——它会被写成一条踩坑记录。

## 约定

- 默认英文，每页都有超链接切换到中文版（`.zh.md`）
- 踩坑记录套用 [`pitfalls/_template.zh.md`](pitfalls/_template.zh.md)——症状/根因/解法/怎么防
- 再小的坑也值得记
